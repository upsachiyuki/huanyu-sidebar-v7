# 寰宇侧边栏 v7

v4 剧场版与 v6 Codex 双皮肤整合的 SillyTavern 客户端扩展，附视觉小说模式 AI 楼层翻页器。

## 安装

1. 把 `huanyu-sidebar-v7/` 整个目录复制到 `SillyTavern/public/scripts/extensions/third-party/`。
2. 刷新 SillyTavern，在「扩展程序」中确认「寰宇侧边栏 v7」已启用。
3. 在扩展设置底部的「寰宇侧边栏 v7」区域选择皮肤和 VN 翻页形态。

首次安装和旧测试设置迁移都保持 SillyTavern 原生主题，不会自动套用 v4/v6；只有在当前面板中明确选择皮肤后，刷新时才会继续应用该皮肤。

## 功能

- **外观版本**：v4 剧场版（深蓝金）与 v6 Codex（暗灰）即时切换。
- **VN 翻页形态**：滑动、书页、幕布或关闭；仅在视觉小说模式下生效。
- **翻页控制**：屏幕左右箭头，或在非输入状态下使用键盘 `←` / `→`。
- **单楼层真分页**：VN 模式保留酒馆原消息 DOM，但一次只显示当前 AI 楼层；切页不再推动聊天容器，长楼层在当前页内部独立滚动。
- **置顶指令卡**：VN 分页时显示当前 AI 楼层之前最近一条用户消息，并随翻页同步；退出 VN 后原用户楼层恢复普通连续聊天。
- **原生主题还原**：可在外观下拉切回原生主题；正式禁用或删除 v7 时也会自动恢复主题、颜色、布局选项和自定义 CSS。
- **动效保护**：系统启用「减少动态效果」时自动取消 ghost 动画。

## 皮肤实现

- v4 使用剧场版完整 CSS。
- v6 使用非剧场版 v4 基础布局作为 host-rail 几何层，再覆盖完整 Codex LIVE_CSS；不依赖用户之前启用过 v4 主题。
- 皮肤启用时暂时清空原主题 `custom_css`，避免样式叠加；还原时会恢复快照。

## 使用提醒

- 通过 SillyTavern 的扩展管理器禁用或删除时，v7 会先自动恢复原生主题；手工删除目录前仍建议先在面板切到「原生主题」。
- 检测到旧版 v6 脚本时，v7 会显示冲突提示并跳过自动皮肤应用；建议二选一。
- 原 v6 脚本创建的独立 Codex 项目侧栏（stock rail）没有移植；v7 使用 SillyTavern 原生侧栏的 host-rail 形态。
- 系统开启 `prefers-reduced-motion` 时，翻页直接切换当前楼层，不播放动画。
